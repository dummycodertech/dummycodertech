## 🎯 Featured Architectures & Research

### **Project 1: Papeer — Agentic RAG Research Assistant**
**[🔗 Repository](https://github.com/dummycodertech/research-assistant-agentic-rag)** ![Status](https://img.shields.io/badge/Status-Active-success?style=flat-square) ![Production](https://img.shields.io/badge/Deployed-AWS%20EC2-blue?style=flat-square) ![Evaluation](https://img.shields.io/badge/Eval-DeepEval-orange?style=flat-square)

A production-ready **agentic retrieval-augmented generation (RAG)** system architected for intelligent research paper discovery and synthesis. Built for **zero-leakage multi-tenant deployment** with robust query routing.

**Technical Metrics & Architecture:**
- **3-Path Agentic Router** using LangGraph: dynamically classifies queries into Direct LLM Generation, Vector Retrieval, or Live ArXiv Verification pathways
- **Self-Correcting Retrieval Loop** with hard-coded max 3 query rewrites — prevents infinite LLM loops and minimizes token waste on ambiguous prompts
- **Automated LLMOps Evaluation Pipeline** via DeepEval: achieved **84.4% Contextual Precision** ![Metric](https://img.shields.io/badge/Precision-84.4%25-brightgreen?style=flat-square) and **74.9% Answer Relevancy** ![Metric](https://img.shields.io/badge/Relevancy-74.9%25-brightgreen?style=flat-square) across 10 golden test sets on complex academic queries
- **Zero-Leakage Multi-Tenant Backend**: Qdrant Cloud vector storage with isolated SQLite checkpointer threads — guarantees **100% session state isolation** for concurrent users
- **Deployment Stack**: AWS EC2 instance with Docker containerization, Groq API for inference optimization, Hugging Face embeddings for semantic search

### **Project 2: Clinical Stroke Predictor — Imbalanced Data & Explainable AI**
**[🔗 Repository](https://github.com/dummycodertech/xai-xgboost-heart_Stroke)** ![Status](https://img.shields.io/badge/Status-Active-success?style=flat-square) ![XAI](https://img.shields.io/badge/Explainable%20AI-SHAP%2FLIME-orange?style=flat-square) ![Healthcare](https://img.shields.io/badge/Domain-Healthcare-red?style=flat-square)

A **high-sensitivity clinical triage model** optimized for rare disease detection in imbalanced datasets. Demonstrates advanced XAI techniques to audit and mitigate algorithmic bias at scale.

**Technical Metrics & Architecture:**
- **Imbalanced Classification Strategy**: 95% negative dataset → Recall-optimized framework achieving **80% Recall** ![Metric](https://img.shields.io/badge/Recall-80%25-brightgreen?style=flat-square) (catches rare positive cases)
- **Algorithmic Balancing (No Synthetic Data)**: Removed SMOTE; leveraged XGBoost's `scale_pos_weight` parameter and lowered clinical decision threshold to **0.15** for maximum disease detection sensitivity
- **Bias Audit via SHAP**: Discovered and mitigated "Age Shield" effect — algorithm disproportionately relied on demographic youth to predict negative outcomes
- **Local Explainability Dashboard**: Streamlit-based interface featuring local LIME explanations for investigating specific false-negative edge cases at individual patient level
- **Validation Pipeline**: Stratified train-test split with cross-validation, handling severe class imbalance through careful threshold optimization
